# Presidenter — Authoring HTML

This is the public host for the `FOUR_CHAINS.html` authoring tool. Open it in any browser:

**https://gokfur.github.io/Presidenter-app/**

The HTML stores your work in `localStorage` (each browser is its own deck) and syncs to a separate private repo via GitHub PAT.

## What this repo contains
- `index.html` — the authoring tool (same as `docs/FOUR_CHAINS.html` in the private `gokfur/Presidenter` repo)

## Where the cards go
The deck JSON is committed to `gokfur/Presidenter-deck` (private) via the ⎇ button inside the HTML. Each contributor uses their own PAT.

## Source repo
The source of truth for the HTML is the private `gokfur/Presidenter` repo. Updates here mirror that.
